# Repository Init プラグイン

## 概要

`repository-init` は、新規および既存リポジトリで明示的に一度だけ呼び出す初期化ワークフローです。初回に決める事項と、後続タスクでも必要な `AGENTS.md` のルールを分離します。

## 設計

- 変更前に対象ルートを確認します。記録がないことだけで新規リポジトリとは判断しません。
- 明確な既存ライセンスを保持します。ライセンスがない、または曖昧な場合だけ一度確認し、選択前にライセンスを作成しません。選択後は MIT を同梱テンプレートから作成し、MIT 以外はユーザーが承認した正確なライセンス本文を使います。
- 不足する `AGENTS.md` と、存在しない場合の英語 `SECURITY.md` だけを作成します。既存固有ルールを保持し、矛盾時は停止します。
- `.repository-init.json` には `schema_version`、`status`、`license`、`language_profile` だけを保存します。中断時は `in_progress`、意味検証後だけ `complete` にします。
- 不正な記録や選択の不一致は上書きせず拒否します。完了後は書き込みません。MIT の一般的な名称は `MIT` に正規化します。
- ロックには所有プロセスと復旧トークンを記録します。停止済みプロセスの stale lock だけを、トークンを指定した明示操作で復旧できます。実行中、不正形式、シンボリックリンクのロックは自動削除しません。
- Git 初期化、リモート作成、Issue／Work Item 作成、Wiki 公開、コミット、プッシュは行いません。

## 言語プロファイル

MIT ではエージェントの応答を日本語、コメント・ドキュメント・コミットを英語とし、必要な翻訳に `_ja.md` を使います。MIT 以外ではコメント、ドキュメント、コミットも日本語にし、`_ja.md` 翻訳は作りません。どちらもセキュリティとライセンス関連ファイルは英語です。

## 検証

状態ヘルパーを、未作成、処理中、完了、中断、競合、不正、実行中／stale lock、明示復旧、MIT 名称の揺れ、アトミック書き込み失敗、ライセンステンプレート、再実行の各ケースで単体テストします。マーケットプレースメタデータとスキルの相対リンクはリポジトリ検証スクリプトで確認します。

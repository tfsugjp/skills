# エージェントインストラクション（参照訳）

このファイルは、MIT 用の `AGENTS.md` を保守担当者が確認するための日本語参照訳です。生成先リポジトリへ追加の実行対象ファイルとしてコピーしてはいけません。

## 継続するルール

- `*_ja.md` を除くリポジトリのコンテキストを作業前に読み取ります。
- 通常の応答は日本語にし、選択した言語プロファイルをコメント、ドキュメント、翻訳、コミットメッセージへ適用します。MIT ではコメント、ドキュメント、コミットメッセージを英語にします。
- 初期開発では後方互換性やデータ移行を追加しません。設計がある場合は設計を先に確定し、仕様変更時は設計を先に更新します。
- スコープを勝手に狭めず、UI はユースケースから情報構造を設計して表示を確認します。
- リモートがある場合は対応する Issue／Work Item と Wiki の運用スキルを使い、スクリプトの説明には Bash と PowerShell 7 を示します。
- `docs/task.md` と `docs/adr.md` の記録規則、URL／IP のプレースホルダー規則、待機規則を守ります。
- `SECURITY.md` とライセンス関連ファイルは英語で作成します。
